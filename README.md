The purpose of this program is to elevate the human cognition and become an
instrument to the mind.
How do we want to do this?
Creating a holistic immersive experience, in which the user has the capability
to express any model of the world they can think of and experiment with it in a
more definite plane.
I need to create a general enough framework that let you express any idea you
want, but in a runnable format (if possible) or evaluate the consequences of
any idea applied in a live environment
